# CISC 3130 Homework 8

This homework focuses on hashing and heaps / priority queues in Java.
The assignment includes:

* Simple hash table implementation
* Separate chaining
* Measuring collisions using load factor
* PriorityQueue with custom comparator
* Heap operations

The code was tested in the console using sample data to make sure everything worked correctly.

Files Included:

* `HashTable.java`
* `Task.java`
* `TaskComparator.java`
* `Main.java`

I used LinkedLists for seperate chaining and Java PriorityQueue for the heap section because it made the operations easier to implement and test.
